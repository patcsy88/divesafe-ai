# Authority map

Who may write what, and which test proves it. This documents what tests enforce; it is not a new
rule (ADR 0025 item 4). Test ids are `file::test name` under `tests/`; every name was checked to
exist. "no test yet" means no test proves the row today; it is a known gap, not a claim of safety.

| Component | May write | May never write | Proving test |
| --- | --- | --- | --- |
| Connectors (`data`) | `EvidenceItem` values with provenance; quality only as a claim, default `unassessed`; typed errors on malformed data | Repaired or coerced values; a quality the engine must accept; partial data presented as complete | `unit/test_forecast_connector.py::test_a_malformed_forecast_is_rejected_not_repaired`; `unit/test_domain_foundation.py::test_quality_defaults_to_unassessed_not_good`; `safety/test_api_human_gate.py::test_evidence_view_reports_the_engines_quality_not_the_connectors_claim` |
| Evidence service | `EvidenceSet`: kept items, `withheld_evidence`, a fixed conflict issue, per-source data versions | A conflicting item into the evaluated set; item content in an issue; a silent drop | `unit/test_evidence_service.py::test_identical_duplicates_collapse_and_conflicts_are_dropped_with_an_issue`; `safety/test_evidence_conflict.py::test_the_issue_never_holds_the_id_or_any_item_content`; `safety/test_evidence_withheld.py::test_withheld_items_reach_neither_the_engine_nor_the_agents_nor_a_prompt_nor_a_citation` |
| Risk engine (`risk`) | Rule results; the most severe result as the deterministic recommendation; expiry and window handling; `CITES_UNUSABLE` flags | `GO` without a rule that said `GO`; a result from an expired rule; a `GO` or `CAUTION` resting on nothing | `safety/test_safety_hierarchy.py::test_engine_takes_most_severe_rule`; `safety/test_rule_definitions.py::test_an_expired_no_go_rule_does_not_silently_become_a_go`; `safety/test_engine_window_and_citation.py::test_an_early_ending_interval_alone_does_not_cover`; `safety/test_engine_window_and_citation.py::test_a_go_or_caution_citing_nothing_is_flagged_as_insufficient_evidence` |
| Engine citation guard, knowledge half | Not built (ADR 0022 decision 8) | n/a | no test yet; a `GO` citing a knowledge item passes today |
| `reconcile` | `final_recommendation` and the downgrade flag: the only producer | A result less severe than either input | `safety/test_safety_hierarchy.py::test_final_is_never_less_conservative_than_either_input`; `safety/test_stage_graph.py::test_propose_is_the_only_producer_of_final_recommendation` |
| Agent proposal (`agents`) | A proposed recommendation with evidence ids; it can only tighten | `final_recommendation`; evidence quality; evidence ids not in the list; a relaxation | `safety/test_agent_safety.py::test_an_llm_proposal_cannot_relax_a_deterministic_insufficient_evidence`; `safety/test_agent_safety.py::test_an_llm_proposal_can_tighten_a_deterministic_go`; `safety/test_agent_safety.py::test_the_proposals_evidence_ids_are_stored_and_validated` |
| Specialists and ToT scenarios | Findings and exactly three scenarios (kind assigned by code), each citing evidence | A reasoning trace; a citation of unknown evidence; a severity | `agent/test_agents_scripted.py::test_scenarios_are_exactly_the_three_kinds_with_evidence`; `safety/test_agent_safety.py::test_extra_fields_such_as_a_reasoning_trace_are_rejected_not_stored`; `safety/test_agent_safety.py::test_a_specialist_citing_unknown_evidence_is_dropped_and_reported` |
| Supervisor (`orchestration.supervisor`) | `supervisor_verdict`; `supervisor.<check>` rule results; a re-run of `reconcile` | Lowering the final recommendation; a call to the provider; a configured rule using its prefix | `safety/test_supervisor.py::test_re_reconciling_after_a_tightening_check_never_relaxes_the_first_final`; `safety/test_supervisor.py::test_supervise_is_code_only_and_never_calls_the_provider`; `safety/test_supervisor.py::test_a_configured_rule_may_not_use_the_supervisor_prefix` |
| Stage trace (`stages`) | One `StageTrace` per executed stage: fixed enums, times, evidence ids, issue codes from the fixed list | Prompts, model text, provider or connector text; an id not in the record | `safety/test_stage_trace.py::test_trace_fields_are_fixed_enums_and_times_only`; `safety/test_stage_trace.py::test_the_trace_never_reads_the_issue_strings`; `safety/test_stage_trace.py::test_a_trace_evidence_id_not_in_the_record_is_refused` |
| Trace influence on routing | Nothing | Routing | no test yet that the router ignores the trace; routing tests use stage outcomes only (`safety/test_stage_graph.py::test_assess_dive_routes_through_next_stage_and_runs_the_work_in_graph_order`) |
| Orchestration graph | Routing between stages from each stage's outcome | Reaching the gate without Assess, Rejudge, Propose and Supervise; a loop or route back | `safety/test_stage_graph.py::test_no_path_reaches_the_gate_without_assess_rejudge_propose_and_supervise`; `safety/test_stage_graph.py::test_a_route_back_to_an_earlier_stage_is_refused_with_no_record` |
| Human gate and decision API | The human decision (decider from credentials, derived `is_override`, rationale); write-once | Replacing a decision; changing the system recommendation; a client-supplied actor or recommendation | Write-once: `safety/test_api_human_gate.py::test_a_decision_cannot_be_replaced`. System recommendation untouched: `safety/test_orchestration.py::test_original_record_is_not_mutated_by_deciding`, and the last assertion of `safety/test_api_human_gate.py::test_override_is_derived_and_needs_a_rationale` (final stays `INSUFFICIENT EVIDENCE` after a `GO` override). Derived `is_override` and rationale: that same test (a `GO` with no rationale or a blank one gets 422; with a rationale it is 200, `is_override` is true and `overrides_to_less_severe` is true; the client never supplies `is_override`). Actor from credentials: `safety/test_api_human_gate.py::test_actor_comes_from_the_credentials_and_cannot_be_supplied`. |
| Create-only API key (assessor) | Create an assessment and read its own | Read the human decision; decide | May never read the decision: `safety/test_api_async_runs.py::test_a_create_only_key_polling_its_finished_run_cannot_read_the_decision` and `safety/test_api_idempotency.py::test_a_create_only_key_cannot_read_a_later_decision_by_repeating_its_create`. May never decide: `safety/test_api_roles_and_limits.py::test_only_a_decider_can_record_the_human_decision` (viewer and assessor POST `/decision` get 403 and `human_decision` stays `None`; a decider gets 200). Create and read only its own: `safety/test_api_roles_and_limits.py::test_an_assessor_can_create_and_read_only_its_own_but_cannot_decide`, which proves the create and own-read part only; its name says "cannot decide" but it never tries to decide. |
| Prompt layer (`agents`) | Delimited untrusted blocks; schema-validated output. Before parsing, `agents/runner.py` (`_json_text`, ~lines 80-83) strips outer whitespace and removes one markdown code fence. Text fields in the schemas (`agents/schemas.py` ~12-14, `strip_whitespace`) are whitespace-stripped on validation. | Repairing a reply: output that fails the schema (bad JSON, extra fields, wrong enum, missing or unknown evidence ids) is rejected, not repaired; cutting an over-long reply down to size (it is refused); letting evidence text close the untrusted block. **Known gap:** duplicate JSON keys are not rejected (`json.loads` keeps the last value), so a reply with a repeated key is accepted with the last value. | Block: `safety/test_agent_safety.py::test_hostile_evidence_text_cannot_close_the_untrusted_block`. Over-long: `safety/test_agent_safety.py::test_an_over_long_reply_is_refused_not_trimmed`. Schema rejection: `safety/test_agent_safety.py::test_a_rejected_risk_output_leaves_the_deterministic_result_standing` (parametrised bad replies give no proposal) and `safety/test_agent_safety.py::test_extra_fields_such_as_a_reasoning_trace_are_rejected_not_stored`. Fence: `agent/test_agents_scripted.py::test_json_in_a_code_fence_is_accepted_but_prose_around_it_is_not` (outside `-m safety`). No test yet for the whitespace and fence handling beyond the fence test above, none for the schema-field stripping, and none for duplicate JSON keys. |
| RAG (`rag`) | Context only, cited by evidence id, with provenance. Retrieval is **not built** (the stage 1 knowledge store and database guards are tested separately) | Live weather, wave, current or tide values; a rule input; LLM text ingested into the corpus | no test yet for "supplies no live values" or "knowledge text never reaches a rule" at retrieval level |

## Reading the table

- A lower layer may keep or tighten a higher layer's result, never relax it (AGENTS.md section 5).
- "May write" names the only component allowed to produce that value; a second writer is a defect.
- ADR 0025 is still `proposed`. This table follows the code as of the `rag-stage-1` branch.
- A new row needs a test that fails when the boundary is crossed (AGENTS.md section 4), not only a
  happy-path test.
